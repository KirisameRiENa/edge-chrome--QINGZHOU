# 清昼 · 简约起始页

一个把「少」做到位的新标签页：大时钟、一句问候、一条搜索、一条正在走的进度线。
纯本地运行，不联网、不注册账号、没有后台进程。支持中文 / English / 日本語。

---

## 安装

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `qingzhou/`
4. 新开一个标签页即可

> 无需打包，也不依赖任何外部资源；断网、隐私模式下同样可用。

| dock 只看置顶 | 设置里一个开关：dock 只留置顶的网页；一条都没置顶时给一句提示，点一下直接开面板。面板始终显示全部，方便随时补置顶 |

## 设计定调

**方向：极致极简，偏编辑感。** 不居中、不摆卡片、不用一排装饰图标。

- **字体**：时钟用 Instrument Serif（高对比衬线，数字等宽 0.56em，分钟跳变不抖）；
  界面用系统中文黑体；微型标签用 JetBrains Mono 全大写、宽字距。
  中文没有引入网络字体——中文字库动辄数 MB，与「低占用」直接冲突，所以只在拉丁部分做差异化。
- **配色**：默认「纸」主题是暖纸底 `#F6F4EF` / 暖墨字 `#1B1917`，深色为 `#121110` / `#EFEADF`。
  强调色只有一个，出现在三处——时钟的冒号、日光进度条、搜索框的聚焦下划线。
  换主题时整套颜色一起走：每套预设只声明 `--bg` 与 `--accent` 两个值，
  表面色、柔和底色、焦点环、背景氛围光全部由 CSS `color-mix()` 从这两个值派生，
  所以加一套新配色只需要写两行 CSS。
  自定义取色会按底色明度反推墨色（浅底用暖墨、深底用米白），避免用户选到深色底时文字看不清。
- **构成**：内容块左偏 `11vw`，右侧留大片空白；整页只有一条竖向对齐线贯穿问候、时钟、日期与搜索框。
- **氛围**：两枚静态径向渐变 + 一层 4% 噪点（`feTurbulence`，只光栅化一次），没有 `blur` 滤镜。
- **记忆点**：时间里的青柠冒号——它是全页唯一的高饱和点，也是唯一会随分钟「呼吸」的细节。

动效只有一次编排好的入场：问候 → 时钟 → 日期 → 搜索 → 底部进度线，间隔 70–90ms；
另有搜索框聚焦时从左侧扫入的 2px 下划线、面板的开合。全部只动 `transform` / `opacity`，
并在 `prefers-reduced-motion: reduce` 下整组关闭。

## 性能

| 项 | 数据 |
| --- | --- |
| 请求数 | 0（字体、图标、样式、收藏夹图标全部本地；导入的图标是 base64 内嵌，不联网） |
| 打包体积 | 解压后 201KB（HTML+CSS+JS 180KB，字体子集 10KB，图标 1.3KB）；zip 压完 68KB |
| 后台脚本 | 无（manifest 里没有 `background`，不占常驻内存） |
| 权限 | 仅 `activeTab`：只在点开扩展图标的那一瞬间，临时读取当前标签页的标题与网址 |
| 定时器 | 全局仅 1 个 `setTimeout`，对齐到下一整分钟；无 `requestAnimationFrame` 循环 |
| DOM 写入 | 分钟跳变时才写；标签页隐藏时不做任何工作，切回时补一次 |
| 本地数据 | 十六个 key：`qz.theme`、`qz.palette`、`qz.custom`、`qz.lang`、`qz.glass`、`qz.bmView`、`qz.sort`、`qz.dockPinned`、`qz.engines`、`qz.progress`、`qz.name`、`qz.wall`、`qz.wallBlur`、`qz.engine`、`qz.history`（≤8 条）、`qz.bookmarks`（≤3000 条） |
| 渲染 | 无 `backdrop-filter`、无大图、无视频；背景为静态渐变 + 一张 160×160 噪点 |

对照参考的青柠起始页（`iframe` 外链线上站点 + 27MB 视频壁纸），本实现是零网络、纯本地。

## 自检

- 对比度：正文 `#736C61` / 纸底 = 4.6:1；深色正文 6.3:1；强调色对纸底 3.2:1（用于图形与进度，文字信息另有标注）
- 焦点：`:focus-visible` 统一 2px 描边 + 2px 偏移；搜索框聚焦时下划线由 1px 变 2px 并变青柠色
- 键盘：`/` 聚焦、`Esc` 收起、单选组方向键可循环切换；按钮触摸区 ≥ 40×40
- 响应式：1440 / 768 / 390 三档无溢出，`@media (max-height: 620px)` 另收紧纵向节奏
- 降级：`prefers-reduced-motion: reduce` 下所有动画与时长为 0.01ms
- 反 AI 味：无 Inter/Roboto、无紫蓝渐变、非居中三卡片、无营销文案、无装饰性图标堆砌
- 收藏夹：导入导出文件实测 6/6 条、重复导入全部跳过；dock 按真实宽度裁剪（12 条 → 8 条 + 省略号，无溢出）、
  编辑保存/重复网址提示/Esc 退编辑、删除、悬浮展开全部通过；卡片用 `content-visibility: auto` 跳过屏外渲染
- 收藏夹面板：44% 半透明填充 + `backdrop-filter: blur(16px) saturate(1.3)` 毛玻璃 + 5% 墨色遮罩；
  面板固定 `min(58vh, 520px)` 高，保证玻璃背后始终压着时钟/搜索——否则模糊一片纯色纸，看起来和不透明没区别
- 收藏管理：无下划线、新建/重命名/删除分类、搜索过滤共 20 条断言全过（删除后条目退回未分类、重命名同步条目、搜索计数与空态）
- 置顶与排序：置顶跳首、dock 同步、最新置顶在前、两种排序生效且置顶不被冲掉，16 条断言全过
- 拖动排序与 dock 开关：面板拖动、网格视图拖动、dock 拖动、空拖不写库、置顶组不可被穿插、非默认排序下拖动自动切回手动、
  置顶即跳到最前、只看置顶的空态与持久化，36 条断言全过（用真实 `DragEvent` 驱动，断言落点是 localStorage 里的顺序）
- 拖动时 dock 不塌：浏览器在拖拽开始时会补 `pointercancel` / `pointerleave`，若照常处理，dock 会在手底下变回进度条
  （排序仍生效但看不见）。现在拖动期间冻结展开态，松手按落点重算；`pointerleave` 抢在 `dragstart` 前到也能补回，14 条断言全过
- 本轮四项：导出 HTML 结构校验、玻璃滑块实时与持久化、视图切换（面板与 dock 同步）、自定义引擎增删与非法网址拦截，共 24 条断言全过
- 三语：中 / 英 / 日切换后逐项核对问候、日期、星期、搜索提示、进度文案、设置标签、配色名、引擎名与 `<html lang>`，全部一致且可切回
- 进度/称呼/背景：三种单位切换、称呼即时更新与持久化、选图→压缩→落盘、模糊实时调节共 22 条断言全过；
  2400×1600 源图压缩到 1600px JPEG（344KB）落在 localStorage 配额内
- 配色：7 套预设 + 自定义，全部实测切换；自定义取色到深底时自动翻转文字色；`color-mix()` 需要 Chrome/Edge 111+
- 历史面板：贴搜索框下沿展开，高度按剩余视口实时计算（不会压住底栏）；超出时可滚动，"清空历史"吸底常驻，
  被裁切的那一行会渐隐；输入网址时不出历史（避免和"直接打开"抢判断）
