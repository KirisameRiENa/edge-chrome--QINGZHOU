清昼 · 简约起始页  v2.3.2
============================

一个本地运行的新标签页：大时钟、日光进度、收藏夹 dock、配色主题、自定义背景。
不联网、无后台进程、不上传任何数据。


一、安装（Chrome / Edge）
------------------------
1. 先解压这个压缩包，得到一个名为 qingzhou 的文件夹（里面能看到 manifest.json）。
2. 打开浏览器，地址栏输入：
   Chrome → chrome://extensions
   Edge   → edge://extensions
3. 打开「开发者模式」
   Chrome 在右上角；Edge 在左下角。
4. 点「加载已解压的扩展程序」（Edge 叫「加载解压缩的扩展」）。
5. 选中整个 qingzhou 文件夹（不是里面的某个文件），确定。
6. 新开一个标签页即可看到。

注意：这个文件夹请放在固定位置，不要移动或删除，浏览器会一直引用这个路径。


二、第一次用建议做的事
----------------------
· 收藏夹：把鼠标移到窗口最底部，点左侧出现的书签图标，
  在面板右上角点「导入书签」，选择浏览器导出的 bookmarks.html
  （Chrome 导出方式：设置 → 导入和导出 → 导出书签）。
· 收藏当前网页：点浏览器工具栏上的清昼图标，小窗里选分类后「添加到收藏夹」。
· 设置：新标签页右上角的滑块图标，可改深浅色、配色、背景图、进度单位、称呼、搜索引擎。
· 语言：右上角「中 / EN / 日」按钮，可在中文、English、日本語之间切换，立即生效。


三、收藏夹怎么玩
----------------
· 导入 / 导出：面板右上角两个按钮，导出的 HTML 可直接导入 Chrome / Edge。
· 两种看法：面板右上角切换「长条列表 / 图标瓦片」，dock 条会一起变。
· 改一条：悬停出 ✎ 与 ×，标题、网址、分类都能改；网址会重新判重。
· 分类：分类行右侧 ＋ / ✎ / 🗑，行内新建与重命名（回车提交、Esc 取消）；
  删除分类时条目不丢，退回「未分类」。
· 搜索：面板顶部搜索框，按标题和网址过滤，命中时计数变成 n/总数。
· 置顶：悬停出图钉，置顶即排到最前（新置顶的在最上面），可随时取消。
· 排序：分类行右侧排序按钮，可选 默认顺序 / 名称 / 网站，置顶项永远在最前。
· 拖动排序：收藏卡片和底部的 dock 条目都能直接拖着改顺序，松手即保存。
  如果当前是按名称或网站排序，拖动一下就会切成手动顺序（会有一句提示）。
· dock 只看置顶：设置 → 「Dock 只显示置顶」开关。
  打开后 dock 上只留你置顶的那几条；一条都没置顶时会显示提示，点一下直接开面板。
  面板里始终显示全部收藏，方便随时补置顶。


四、快捷键
----------
/        聚焦搜索框
Esc      逐层收起（设置面板 → 搜索历史 → 收藏夹 → 失焦）
↓        从搜索框进入搜索历史列表
Ctrl/⌘ + 点击收藏  → 新标签页打开
收藏夹面板里按 Esc：只退出编辑，不收起面板


五、环境要求
------------
Chrome / Edge 111 或更高版本（用到了 CSS color-mix 与 backdrop-filter）。


六、更新到新版本（很重要）
--------------------------
浏览器会把扩展的文件缓存起来，只换文件、不点「刷新」的话，
跑的还是旧代码——新标签页右下角那个版本号也不会变。

正确步骤：
1. 把新压缩包里的 qingzhou 文件夹，整个覆盖到你现在用的那个文件夹
   （路径要和当初「加载已解压的扩展程序」时选的完全一致）。
2. 打开 chrome://extensions（Edge 为 edge://extensions）。
3. 在「清昼」这张卡片上点一下刷新按钮（一个圆形箭头）。
4. 关掉所有已打开的新标签页，再新开一个。
5. 看右下角：版本号变成 2.3.2 才说明换成功了。

如果扩展列表里有两张「清昼」，说明新旧都装着：
删掉旧的那张（或点「移除」），只留一份。


七、关于隐私
------------
· 所有设置与收藏都存在浏览器的本地存储里，不上传、不同步。
· 扩展不发起任何网络请求；收藏夹图标是导入文件里自带的内嵌图片。
· 唯一申请的权限是 activeTab：只在点开工具栏图标的那一瞬间，
  临时读取当前标签页的标题和网址，用来收藏。
